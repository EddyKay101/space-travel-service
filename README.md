# Space Travel Service

A prototype government-style service that allows users to choose a destination for space travel and provide their personal details.

This project was created as part of an Interaction Designer pre-interview exercise using the GOV.UK Prototype Kit and GOV.UK Design System.

## About the project

The prototype demonstrates a simple user journey, from selecting a destination to reviewing the information provided.

Users can choose between travelling to the Moon or Mars. Depending on their selection, they are directed through a destination-specific page before entering their name and address.

At the end of the journey, users can review their answers and make changes before submitting.

## Features

- Destination selection with branching between Moon and Mars
- Collection of name and address details
- Session data used to retain answers between pages
- Check your answers page with options to change previous responses
- Basic form validation
- Confirmation page following submission
- Responsive layouts using GOV.UK Design System components

## Built with

- GOV.UK Prototype Kit
- GOV.UK Design System
- Node.js
- Express
- Nunjucks

## Running locally

Install dependencies:

`npm install`

Start the prototype:

`npm start`

Open `http://localhost:3000` in your browser.

## Deployment

The prototype is hosted on Render.

Live prototype: https://space-travel-service-6cjx.onrender.com/

## Note

This is an imaginary service created for demonstration purposes. No real space travel applications are processed or submitted.
